# Prévia visual BÉLIN

HTML separado da aplicação Next.js, exportado das páginas públicas para apresentação do design. Os exemplos de peças são demonstrativos. Navegação e menu mobile funcionam; ações de backend e controles da aplicação mostram um aviso de prévia. Não há upload, login, pedidos ou IA neste pacote.

Para atualizar, inicie a aplicação local na porta 3000 e execute `node scripts/export-frontend-preview.cjs`. Confira as páginas e os assets antes de publicar. Somente o conteúdo de `frontend-preview/` deve ir para a branch de publicação `gh-pages`; não publique a raiz da aplicação nem a pasta de documentação interna.
