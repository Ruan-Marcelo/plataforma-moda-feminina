# Instruções do projeto

- Preserve a separação entre UI, serviços, persistência e integrações externas.
- Use TypeScript strict, validação com Zod e autorização no servidor.
- Não invente dados de catálogo, métricas, credenciais ou integrações.
- Execute typecheck, lint e testes relevantes antes de concluir mudanças.
- Nunca versionar .env, chaves ou imagens pessoais do provador.
- Documente decisões arquiteturais significativas em docs/adr/.
